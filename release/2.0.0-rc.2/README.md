# EBO 2.0.0-rc.2 candidate

This unpublished candidate reads ATIF through a producer-independent core and freezes execution software per study. EBO maintains eight native harnesses: Claude Agent SDK, Codex, Devin CLI, Cursor, Pi, Factory Droid, OpenHands and DeepSeek Harness.

Conforming ATIF documents can be read, projected, visualized and measured without a producer overlay. Pi and Codex overlays interpret demonstrated extensions and record their reasons. Unknown producer and minor versions retain core analysis with confidence limits. Measures describe the recorded document; completeness of an entire attempt requires separate evidence. The [coverage matrix](../../docs/reference/atif-harness-coverage.md) explains each native and upstream surface.

[Study runtime locks](../../docs/reference/study-runtimes.md) select exact age-eligible releases, retain dependency integrity and offered provenance, and check OSV at resolution and before launch. Every arm, rerun, judge and Harbor worker consumes its study’s lock. Runtime probes record the software that ran. Deprecated transitive dependencies appear as operator warnings and remain in receipts.

[Migration](MIGRATION.md) covers retained imports, native bundles and new execution setup. [Qualification](QUALIFICATION.md) covers deterministic packaging and cold readback. The [reproducibility manifest](reproducibility.json) binds this candidate’s source inputs. Qualification produces a receipt with the actual source commit and archive digest. It does not publish a package or create a release tag.
